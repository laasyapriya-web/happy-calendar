# Happy Calendar 📅✨

A beautiful, interactive calendar app for tracking your daily happy moments. Built with React, Tailwind CSS, and love ❤️.

## 🌟 Live Demo
https://happy-calendar.vercel.app/
## ✨ Features

### 🎨 Beautiful Design
- **4 Color Themes**: Pastel Dreams, Lavender Fields, Mint Fresh, Peachy Keen
- **Dark/Light Mode**: Toggle between light and dark themes
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Rounded UI Elements**: Soft, friendly interface

### 📝 Happy Moments Tracking
- **Daily Entries**: Click on any date to add/edit your happy moment
- **Message Preview**: See entry previews directly on calendar tiles
- **Search Functionality**: Find specific moments instantly
- **Local Storage**: Automatic saving in your browser

### 🏆 Gamification
- **Achievements System**: 5 unlockable achievements
- **Progress Tracking**: Visual streak indicators
- **Milestones**: Daily, weekly, and monthly goals

### 📁 Data Management
- **Export Data**: Save entries as JSON file
- **Import Data**: Load saved entries
- **Export Image**: Save calendar as PNG
- **Auto-save**: Changes saved automatically

### 🔧 User Experience
- **Intuitive Navigation**: Easy month navigation
- **Visual Feedback**: Heart icons on filled dates
- **Touch-Friendly**: Mobile optimized
- **Smooth Animations**: Pleasant hover effects

## 🚀 Quick Start

Navigate: Use Previous/Next buttons

Customize: Change themes, toggle dark mode

Export: Save data as JSON or image
